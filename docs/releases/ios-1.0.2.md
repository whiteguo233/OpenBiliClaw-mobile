## 中文更新说明

新增扫码连接后端：在连接设置的后端 URL 旁点击扫码图标，扫描电脑 Web 或插件的连接二维码，自动保存地址并重连。

扫码页支持从系统相册选择二维码截图，图片仅在设备本地识别，相机不可用时也可使用。

支持局域网、Tailscale 和公网连接地址，保留端口和反向代理路径，并改进连接检测与相机切后台后的恢复。
